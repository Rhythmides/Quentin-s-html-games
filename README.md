

# Quentin's HTML Games

## Overview

Quentin's HTML Games is a collection of browser-based games and interactive experiences, all created through AI-generated content (AIGC) workflows. The project was initiated and conceptualized by Quentin, with all game mechanics, code, and content generated by DeepSeek and ChatGPT. Each game is a standalone HTML file that runs directly in any modern web browser — no installation, no build step, no dependencies required.

## About This Project

This repository serves as a showcase of what is possible when human creativity meets AI generation capabilities. Quentin provided the initial ideas, design direction, and creative vision; the AI models handled the implementation — from game logic and rendering to UI and interactivity. The result is a diverse set of playable experiences spanning multiple genres, all packaged as self-contained HTML files.

The project demonstrates a new paradigm in game development: rapid prototyping and creation through human-AI collaboration, where the barrier between "idea" and "playable product" is dramatically reduced.

## Games Included

| Game | File | Description |

Each game is entirely self-contained. Open the HTML file in any modern browser (Chrome, Firefox, Edge, Safari) and start playing immediately. No internet connection is required after the file is downloaded.

## Technical Details

All games are built with vanilla HTML, CSS, and JavaScript. No external libraries, frameworks, or assets are needed — everything is embedded within each HTML file. This makes the project extremely portable: you can copy any file to a USB drive, email it, or host it on any web server, and it will work.

The games were generated by DeepSeek and ChatGPT based on Quentin's ideas, then uploaded to this repository. The version numbers in filenames (e.g., "2.3", "3.1") reflect iterations in the AI generation process — each number represents a distinct generation pass, often with refinements in gameplay, UI, or bug fixes.
